# Krentoraan

{% include components/project_banner.html %}

<div lang="en" markdown="1">

Krentoraan is a Skyrim Anniversary Edition modlist of about 1,350 mods that changes how the game looks and keeps the way it plays close to vanilla.

## Quick Links

- [Installation Guide]({{ '/krentoraan/installation-guide/' | relative_url }})
- [Load Order]({{ '/krentoraan/loadorder/' | relative_url }})

## About This Modlist

Most of the list is visual: about 660 texture and mesh mods, ENB lighting, new grass and trees. Only about 55 mods change gameplay, combat or characters, so the game plays like the one you know.

### Key Features

- **Lighting**: NAT.ENB III with Lux, Lux Via and Lux Orbis for interiors, roads and cities, and ENB lights on hundreds of objects.
- **Landscapes**: Cathedral 3D grass and plants, Folkvangr and Veydosebrom grass, and reworked trees.
- **Textures and meshes**: About 660 mods replace the game's textures and models.
- **Close to vanilla**: About 55 mods change gameplay, combat or characters: the game plays like the one you know.
