# Preamble

This mod list is for Skyrim Special Edition on Steam with the Anniversary Edition upgrade: it uses all the Creation Club content that comes with Anniversary Edition. Keep the game updated by Steam and do not downgrade it yourself. During the install, Wabbajack copies the game into the list's `Game Root` folder and turns that copy into game version 1.6.1170, the version the list's SKSE plugins are made for. The list does not work with Skyrim Legendary Edition, nor with Special Edition without the Anniversary upgrade.

This list will only work with a legitimate Steam install of this game. It will not work with any other platform (like GOG). Install the game in English: Wabbajack needs the English voice files. This modlist is focused mostly on graphics and textures.

> "I decided to create this modlist because people kept asking how I got Skyrim to look so good. I know that when you begin, it can be hard to mod correctly and you can quickly be lost, but following this guide will help you build the Skyrim of your dreams! This very extended and detailed modlist will help you understand modding, minimizing bugs and conflicts to allow for a completely immersive gameplay experience. This is how I think the game is perfect, but if you think something could be better, the choice is yours. For each graphic mod I use 2K resolution, but you should install a range between 1K and 4K (8K sometimes, if your PC can handle it). I don't recommend installing less than 1K resolution textures."

This modlist is a heavy 3600+ mod list based on my personal preferences. It improves almost everything from the vanilla game to make it look more like a 2023 game than a 2011 game. Wunduniik is a draconic word meaning "Traveler".

# Préambule

Cette modlist est conçue pour Skyrim Special Edition sur Steam avec la mise à niveau Anniversary Edition : elle utilise tout le contenu Creation Club fourni avec l'Anniversary Edition. Laissez Steam tenir le jeu à jour et ne le rétrogradez pas vous-même. Pendant l'installation, Wabbajack copie le jeu dans le dossier `Game Root` de la liste et convertit cette copie en version 1.6.1170, la version pour laquelle les plugins SKSE de la liste sont prévus. La liste ne fonctionne pas avec Skyrim Legendary Edition, ni avec la Special Edition sans la mise à niveau Anniversary.

Cette liste ne fonctionnera qu'avec une installation Steam légitime du jeu. Elle ne fonctionnera pas sur d'autres plateformes (comme GOG). Installez le jeu en anglais : Wabbajack a besoin des fichiers de voix anglais. Cette modlist est principalement axée sur les graphismes et les textures.

> « J'ai décidé de créer cette modlist parce que les gens me demandaient sans cesse comment j'avais rendu Skyrim si beau. Je sais qu'au début, il peut être difficile de modder correctement et on peut vite se perdre, mais ce guide vous aidera à construire le Skyrim de vos rêves ! Cette modlist très complète et détaillée vous aidera à comprendre le modding en minimisant les bugs et les conflits pour une expérience de jeu totalement immersive. C'est ainsi que je pense que le jeu est parfait, mais si vous pensez que quelque chose pourrait être mieux, le choix est le vôtre. Pour chaque mod graphique, j'utilise la résolution 2K, mais vous devriez installer entre 1K et 4K (8K parfois, si votre PC peut le supporter). Je ne recommande pas d'installer des textures en dessous de la résolution 1K. »

Cette modlist comporte plus de 3600 mods basés sur mes préférences personnelles. Elle améliore presque tout du jeu vanilla pour lui donner l'apparence d'un jeu de 2023 plutôt que de 2011. Wunduniik est un mot draconique signifiant « Voyageur ».
