# Controls

{: .short }
> **In short**
> - Press **F8** in game for the full keymap (Tab closes it). The same map is on the [Using The List]({{ '/wunduniik/installation-guide/using-the-list/' | relative_url }}) page.
> - Sprint is on **Left Alt**, walk/run toggle on **Caps Lock**.
> - The right mouse button power attacks. **Left Shift** is a modifier: Shift + right click blocks, Shift + left click power attacks, Shift + E gives the alternate interaction.
> - Dodge, target lock and the bow rapid combo sit on extra mouse buttons: check F8 for which one.
> - Settings menus: **F1** SKSE Menu Framework, **Home** dMenu, plus the usual MCM in the pause menu.

The tables below list the keyboard binds shown by the list's own F8 keymap. Keys not listed keep their vanilla role.

# Commandes

{: .short }
> **En bref**
> - Appuyez sur **F8** en jeu pour la carte complète des touches (Tab pour fermer). La même carte figure sur la page [Utiliser la liste]({{ '/wunduniik/installation-guide/using-the-list/' | relative_url }}).
> - Le sprint est sur **Alt gauche**, la bascule marche / course sur **Verr. Maj**.
> - Le clic droit fait une attaque puissante. **Maj gauche** sert de modificateur : Maj + clic droit pour bloquer, Maj + clic gauche pour une attaque puissante, Maj + E pour l'interaction alternative.
> - L'esquive, le verrouillage de cible et le tir rapide à l'arc sont sur des boutons de souris supplémentaires : vérifiez lesquels avec F8.
> - Menus de réglages : **F1** SKSE Menu Framework, **Origine** dMenu, en plus du MCM habituel dans le menu pause.

Les tableaux ci-dessous reprennent les touches clavier affichées par la carte F8 de la liste. Les touches absentes gardent leur rôle vanilla. Les noms de touches correspondent à un clavier QWERTY, comme sur la carte F8.
