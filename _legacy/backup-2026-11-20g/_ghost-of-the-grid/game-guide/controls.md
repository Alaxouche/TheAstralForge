# Controls

{: .short }
> **In short**
> - Keyboard and mouse bindings below come from the list's input files and its Mod Settings values.
> - End opens the CET overlay. F8 opens the RCF settings hub and also toggles the HUD.
> - Number keys 1 to 8, then 9, 0, V, B, R, T, Y, U pick quickhacks directly.
> - Dialogue choices use Q / E or the mouse wheel: W and S no longer move the selection.
> - Most CET hotkeys (Weapon Loadouts, Car Selection Menu, Weather Switcher...) ship unbound. Bind them in the CET overlay.

## Menus and interface

| Key | Action | Mod |
| --- | --- | --- |
| End | Open the CET overlay (console, CET mods, CET hotkeys) | Cyber Engine Tweaks |
| F8 | Open the Redscript Configuration Framework hub | Redscript Configuration Framework |
| F8 | Show or hide the whole HUD | [Limited HUD](https://www.nexusmods.com/cyberpunk2077/mods/2592) |
| F6 | Show or hide the minimap | Limited HUD |
| Q / E, mouse wheel | Move up / down in dialogue choices (W and S are disabled there) | [Disable W-S Keys For Select Dialogue Options](https://www.nexusmods.com/cyberpunk2077/mods/9799) |
| S | Inventory: mark the selected item as junk | [Mark To Sell](https://www.nexusmods.com/cyberpunk2077/mods/4725) |
| A | Inventory: mark every item of the same type and quality as junk | Mark To Sell |
| Z / C | Crafting: previous / next weapon variant | [Enhanced Craft](https://www.nexusmods.com/cyberpunk2077/mods/4378) |
| 4 | Metro: show or hide the route widget | [Metro Pocket Guide](https://www.nexusmods.com/cyberpunk2077/mods/11882) |

{: .note }
F8 is used by two mods. If the RCF hub or the HUD toggle doesn't respond, change one of them: Limited HUD's key is in Mod Settings.

## Drone companions

[Drone Companions Revamp](https://www.nexusmods.com/cyberpunk2077/mods/23980) uses: O drive, G jack, X lure, Left Ctrl cloak, V view, 5 mark, F2 repair, F4 handling, F6 spoof, left and right mouse to select and move.

{: .note }
Some of these keys overlap with others (F2, F6, V, R, T). Most of them only work in their own context (scanner open, drone active, in a vehicle). If two actions fight over a key, rebind one in Mod Settings or in the game's controls menu.

## Unbound hotkeys

These CET hotkeys ship with no key. Open the CET overlay (End), Bindings tab, to set them:

- Weapon Loadouts: switch between saved loadouts.
- Car Selection Menu: summon, next or previous manufacturer, favourite.
- Skip Unskippable Cutscenes: fast forward.
- Weather Switcher, LUT Switcher: weather, time and colour grading.
- Semi-automatic Transmission: gear changes.

## Drones compagnons

[Drone Companions Revamp](https://www.nexusmods.com/cyberpunk2077/mods/23980) utilise : O piloter, G pirater, X attirer, Ctrl gauche camouflage, V vue, 5 marquer, F2 réparer, F4 maniabilité, F6 leurre, clics gauche et droit pour sélectionner et déplacer.

{: .note }
Certaines de ces touches se recoupent (F2, F6, V, R, T). La plupart ne marchent que dans leur contexte (scanner ouvert, drone actif, en véhicule). Si deux actions se disputent une touche, changez-en une dans Mod Settings ou dans le menu des commandes du jeu.

## Raccourcis non attribués

Ces raccourcis CET n'ont pas de touche par défaut. Ouvrez l'overlay CET (Fin), onglet Bindings, pour les régler :

- Weapon Loadouts : passer d'un équipement enregistré à l'autre.
- Car Selection Menu : appeler, constructeur suivant ou précédent, favori.
- Skip Unskippable Cutscenes : avance rapide.
- Weather Switcher, LUT Switcher : météo, heure et étalonnage des couleurs.
- Semi-automatic Transmission : changements de vitesse.
