# Skill Trees

{: .short }
> **In short**
> - 83 skills in five trees (Combat, Science, Tech, Physical, Social), four tiers each, four ranks per skill. Read from the list's own plugins, in load order.
> - With Royal Galaxy, 3 points spent in a tree open its next tier (the game asks for 4).
> - A rank only opens once you finish its challenge; the exact count is under each rank ("Next rank").
> - Deadly Effective reworks and renames several combat skills (Neutralisation, Focus, Evasion...). Shades Stealth Takedowns adds Takedowns.
> - A gold dot marks a skill changed by a mod, a blue one a skill a mod adds. The table says which mod has the last word.

The French names and texts are the game's official ones wherever the mod keeps the English text unchanged; a skill rewritten by a mod shows the mod's English text.

{: .note }
Fitness: Perk Up's page lists +30 / 60 / 100% oxygen, but StarGym loads later and its version of the skill (10 / 20 / 30%) is the one the game shows.

# Arbres de compétences

{: .short }
> **En bref**
> - 83 compétences dans cinq arbres (Combat, Science, Technologie, Physique, Social), quatre paliers chacun, quatre rangs par compétence. Lues dans les plugins de la liste, dans l'ordre de chargement.
> - Avec Royal Galaxy, 3 points dépensés dans un arbre ouvrent son palier suivant (le jeu en demande 4).
> - Un rang ne s'ouvre qu'une fois son défi terminé ; le nombre exact figure sous chaque rang (« Rang suivant »).
> - Deadly Effective refait et renomme plusieurs compétences de combat (Neutralisation, Focus, Evasion...). Shades Stealth Takedowns ajoute Takedowns.
> - Un point doré marque une compétence modifiée par un mod, un point bleu une compétence ajoutée par un mod. Le tableau indique le mod qui a le dernier mot.

Les noms et textes français sont ceux du jeu partout où le mod garde le texte anglais d'origine ; une compétence réécrite par un mod affiche le texte anglais du mod.

{: .note }
Forme (Fitness) : la page de Perk Up annonce +30 / 60 / 100 % d'oxygène, mais StarGym se charge après et sa version de la compétence (10 / 20 / 30 %) est celle que le jeu affiche.
