## Installation

Once you have completed pre-installation, download the latest version of Wabbajack and place it in a folder such as `C:\Games\Wabbajack`.

Downloading and installing Extrasolar Containment Protocol can take a while. Follow these steps:

1. Open Wabbajack and click on **Browse Modlists**.
2. Search for **Extrasolar Containment Protocol**.
3. Press the download button and wait for the `.wabbajack` file to finish downloading.
4. Press the play button that replaces the download button.
5. Set the installation folder to somewhere like `C:\Games\ExtrasolarContainmentProtocol` and the download folder to somewhere like `C:\Games\ExtrasolarContainmentProtocol\Downloads`. The download location does not need to be on an SSD but it makes installing faster.
6. Start the installation. Log in to Nexus Mods when Wabbajack asks for it.
7. Go enjoy a coffee while Wabbajack does its thing.
8. The installation is now complete. Move on to the next section.

**Even if Wabbajack says installation complete, this doesn't mean you have finished. You must follow the rest of the installation guide in order to have the list working properly.**

## Installation

Une fois la pré-installation terminée, téléchargez la dernière version de Wabbajack et placez-le dans `C:\Games\Wabbajack`.

Le téléchargement et l'installation d'Extrasolar Containment Protocol peuvent prendre un certain temps. Suivez ces étapes :

1. Ouvrez Wabbajack et cliquez sur **Browse Modlists** (parcourir les modlists).
2. Recherchez **Extrasolar Containment Protocol**.
3. Appuyez sur le bouton de téléchargement et attendez la fin du téléchargement du fichier `.wabbajack`.
4. Appuyez sur le bouton lecture qui remplace le bouton de téléchargement.
5. Définissez le dossier d'installation quelque part comme `C:\Games\ExtrasolarContainmentProtocol` et le dossier de téléchargement quelque part comme `C:\Games\ExtrasolarContainmentProtocol\Downloads`. L'emplacement de téléchargement n'a pas besoin d'être sur un SSD, mais cela accélère l'installation.
6. Lancez l'installation. Connectez-vous à Nexus Mods quand Wabbajack le demande.
7. Allez profiter d'un café pendant que Wabbajack travaille.
8. L'installation est terminée. Passez à la section suivante.

**Même si Wabbajack dit que l'installation est terminée, vous n'avez pas fini. Vous devez suivre le reste du guide d'installation pour que la liste fonctionne correctement.**

## Problems With Installation

**Could not download x:**
Big files can fail to download due to connection issues. Run Wabbajack again first. If a file still fails, open the latest log in the `logs` folder of your Wabbajack version folder: it ends with links to the files that failed. Download them by hand into your downloads folder (delete any incomplete copy of the file there first), then run the installation again.

**Wabbajack could not find the game folder:**
Make sure Starfield is installed via Steam and that you have launched it at least once. Verify game files in Steam if necessary.

**A game file does not match:**
Wabbajack reads files from your Starfield folder and expects version 1.16.244. Verify game files in Steam, check that the game is on 1.16.244 and that no mod was installed into the game folder by hand.

**Installation fails partway through:**
Check that your antivirus is not blocking Wabbajack or the installation directory. Add both to your exclusions and try again.

## Problèmes d'Installation

**Impossible de télécharger x :**
Les gros fichiers peuvent échouer à cause de problèmes de connexion. Relancez d'abord Wabbajack. Si un fichier échoue encore, ouvrez le dernier journal dans le dossier `logs` du dossier de version de Wabbajack : il se termine par les liens des fichiers en échec. Téléchargez-les à la main dans votre dossier de téléchargement (supprimez d'abord toute copie incomplète du fichier), puis relancez l'installation.

**Wabbajack ne trouve pas le dossier du jeu :**
Assurez-vous que Starfield est installé via Steam et que vous l'avez lancé au moins une fois. Vérifiez les fichiers du jeu dans Steam si nécessaire.

**Un fichier du jeu ne correspond pas :**
Wabbajack lit des fichiers dans votre dossier Starfield et attend la version 1.16.244. Vérifiez les fichiers du jeu dans Steam, assurez-vous que le jeu est en 1.16.244 et qu'aucun mod n'a été installé à la main dans le dossier du jeu.

**L'installation échoue en cours de route :**
Vérifiez que votre antivirus ne bloque pas Wabbajack ou le répertoire d'installation. Ajoutez les deux à vos exclusions et réessayez.
