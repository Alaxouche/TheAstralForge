# Preamble

This mod list is for Starfield on Steam, game version **1.16.244**. It will only work with a legitimate Steam install of the game. It will not work with any other platform (like Xbox Game Pass PC or the Microsoft Store): Wabbajack supports Starfield on Steam only, and the Starfield Script Extender (SFSE) the list needs only runs on the Steam version.

You also need both expansions installed through Steam: **Shattered Space** and **Terran Armada** (both are included in the Premium Edition). Many plugins in the list require them, and the game will not load the list without them.

This modlist is focused on enhanced visuals, immersive gameplay, and expanded exploration across the settled systems.

# Préambule

Cette modlist est conçue pour Starfield sur Steam, version du jeu **1.16.244**. Elle ne fonctionnera qu'avec une installation Steam légitime du jeu. Elle ne fonctionnera pas sur d'autres plateformes (comme Xbox Game Pass PC ou le Microsoft Store) : Wabbajack ne prend en charge Starfield que sur Steam, et le Starfield Script Extender (SFSE) dont la liste a besoin ne fonctionne qu'avec la version Steam.

Cette modlist est axée sur des visuels améliorés, un gameplay immersif et une exploration étendue à travers les systèmes colonisés.
