{% comment %} components/gallery.html Renders a screenshot grid for a modlist when `page.gallery_path` is set in front matter (e.g. gallery_path: "/assets/Images/Skyrim/"). Images are pulled straight from site.static_files, so dropping new screenshots in the folder is enough — no list to maintain. What the browser downloads: the grid tiles are ~220px CSS, so the srcset only offers the 400w and 800w derivatives from assets/thumbs (built by scripts/optimize-images.sh). Clicking opens the lightbox on the 1600w derivative via data-full — the 2560px master is never sent to a visitor. Alt text: real captions live in _data/gallery_captions.yml, keyed by the bare filename. Anything unlisted falls back to a numbered label so the images are at least distinguishable to a screen reader. {% endcomment %} {% if page.gallery_path %} {% assign gallery_files = site.static_files | where_exp: "f", "f.path contains page.gallery_path" %} {% assign gallery_images = gallery_files | where_exp: "f", "f.extname == '.webp' or f.extname == '.jpg' or f.extname == '.jpeg' or f.extname == '.png'" | sort: "path" %} {% if gallery_images.size > 0 %} {% assign captions = site.data.gallery_captions.captions %}
