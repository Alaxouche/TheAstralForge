# Perk Trees

{: .short }
> **In short**
> - 196 perks: the five attribute trees and the Relic tree, read from the game's own data with the list's mods applied.
> - Each row of a drawing is a tier. You need 4, 9, 15 or 20 points in the attribute to buy its perks. Relic perks use Relic points.
> - Big stars are milestone perks; the small ones around them need them first. Lines show what each perk requires.
> - Running Man fills the empty Novice slots of Body with three sprint perks. Perks with a gold dot are changed by a mod of the list.
> - Numbers and texts are the game's. Perks And Skills Fixes adjusts some values in game, depending on its settings: those perks say so.

The drawings show how the perks connect, not their exact place on the game screen. The Bullet Ballet tree for handguns and revolvers is separate (Custom Perk Framework): it is described on the [Character]({{ '/ghost-of-the-grid/game-guide/character/' | relative_url }}) page.

# Arbres de perks

{: .short }
> **En bref**
> - 196 perks : les cinq arbres d'attributs et l'arbre Relic, lus dans les données du jeu, avec les mods de la liste appliqués.
> - Chaque rangée d'un dessin est un palier. Il faut 4, 9, 15 ou 20 points dans l'attribut pour acheter ses perks. Les perks Relic utilisent les points Relic.
> - Les grandes étoiles sont les perks majeurs ; les petites autour d'elles les demandent d'abord. Les traits montrent ce que chaque perk exige.
> - Running Man remplit les emplacements Novice vides de Constitution avec trois perks de sprint. Les perks marqués d'un point doré sont modifiés par un mod de la liste.
> - Les chiffres et les textes sont ceux du jeu. Perks And Skills Fixes ajuste certaines valeurs en jeu selon ses réglages : ces perks l'indiquent.

Les dessins montrent comment les perks se relient, pas leur place exacte à l'écran. L'arbre Bullet Ballet pour les pistolets et revolvers est à part (Custom Perk Framework) : il est décrit dans la page [Personnage]({{ '/ghost-of-the-grid/game-guide/character/' | relative_url }}).
