# Preamble

No Man's Sky - Explorer 3.1.0.0 is built and tested on **No Man's Sky 7.14** (Forsaken update, November 2026). Install the game at that version; older versions are not supported. Once the list is installed, hold back automatic game updates: a new patch can break mods until the list is updated for it.

This list only works with a legitimate **Steam** or **GOG** copy of the game. The Microsoft Store / Xbox app (Game Pass) version is not supported: Wabbajack only supports Steam and GOG for No Man's Sky. This modlist is focused mostly on graphics, interface, and gameplay.
