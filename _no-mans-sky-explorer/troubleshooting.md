## Crash Logs

The list has no crash logger: No Man's Sky has no script extender to host one. When the game crashes:

1. Check the game version. After a patch from Hello Games, mods can stop working until the list is updated: see [When The Game Updates]({{ '/no-mans-sky-explorer/installation-guide/n-using-the-list/' | relative_url }}#when-the-game-updates).
2. Check that the `GAMEDATA\MODS` folder in the game folder holds no mod you installed by hand.
3. If mods do not load at all, see [If Mods Do Not Load]({{ '/no-mans-sky-explorer/installation-guide/n-using-the-list/' | relative_url }}#if-mods-do-not-load).

</div>

## Journaux de crash

La liste n'a pas d'enregistreur de plantages : No Man's Sky n'a pas d'extenseur de script pour en accueillir un. Quand le jeu plante :

1. Vérifiez la version du jeu. Après un patch de Hello Games, des mods peuvent cesser de fonctionner jusqu'à la mise à jour de la liste : voyez [Quand le jeu se met à jour]({{ '/no-mans-sky-explorer/installation-guide/n-using-the-list/' | relative_url }}#quand-le-jeu-se-met-a-jour).
2. Vérifiez que le dossier `GAMEDATA\MODS` du jeu ne contient aucun mod installé à la main.
3. Si les mods ne se chargent pas du tout, voyez [Si les mods ne se chargent pas]({{ '/no-mans-sky-explorer/installation-guide/n-using-the-list/' | relative_url }}#si-les-mods-ne-se-chargent-pas).

</div>

## Reporting a Crash

When you ask for help on [Discord](https://discord.gg/vKuB7nazBk), send:

- the game version;
- the list version and the profile you play;
- what you were doing when it crashed, and whether it happens every time.

</div>

## Signaler un plantage

Quand vous demandez de l'aide sur [Discord](https://discord.gg/vKuB7nazBk), envoyez :

- la version du jeu ;
- la version de la liste et le profil utilisé ;
